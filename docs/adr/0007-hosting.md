# ADR 0007: Render as the documented API target

Date: 19 November 2026. Status: implemented AI draft, awaiting Rajat review.

## Context

The project needs a concrete deployment procedure without claiming deployment.

## Options considered

Railway is also compatible; choose after checking current plans, backups, region and cost.

## Decision

Document Render Docker, Atlas, Vercel, and EAS as operator-run targets.

## Consequences

No provider resources were provisioned. Check current pricing and complete smoke tests before launch.

## Evidence

Runbook procedures; Docker image build passed; runtime smoke testing remains incomplete after daemon disconnection.
